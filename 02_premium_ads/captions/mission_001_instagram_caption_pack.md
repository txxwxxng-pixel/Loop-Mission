# Mission 001 Instagram Caption Pack

## Campaign

Loop Mission - Build The Studio Loop

## Source Direction

Use these captions for the first Loop Mission launch posts. The tone should be premium, operational, and concrete. Avoid hype about AI doing everything. Emphasize disciplined production, one mission at a time, real outputs, QA, archive, and next-step handoff.

## Tone Notes

- Confident but not loud.
- Practical, not motivational.
- Premium studio language, not generic productivity language.
- Codex is framed as an execution worker inside clear rules.
- Every caption should point to a real production behavior.

## Usage Recommendations

- Use carousel captions for multi-slide education posts.
- Use short-form video captions for Reels showing the idea-to-output transformation.
- Use premium brand statements as single-image post copy, profile copy, or landing-page seed copy.
- Pair Korean and English versions according to audience. Do not mix both languages in one post unless the creative is intentionally bilingual.
- Keep the first line short enough to work as the Instagram preview hook.
