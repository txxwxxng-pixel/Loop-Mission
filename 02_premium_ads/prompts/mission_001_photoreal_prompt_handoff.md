# Mission 001 Photoreal Prompt Handoff

## Handoff Target

Future loop: `04_photoreal_prompts/`

Source loop: `02_premium_ads/`

## Purpose

Provide clear creative direction for a future photorealistic image prompt pack. This file is a handoff only; no images are generated in this mission.

## Core Visual Subject

A premium one-person AI studio workspace designed around five production loops: interactive web, premium ads, Unreal spaces, photoreal prompts, and Unity/game commerce.

## Required Prompt Outputs Later

- Full prompt for the campaign hero image.
- Compact prompt for quick image generation.
- Negative prompt to avoid common AI-image failures.
- Variation prompts for carousel and Reel frames.
- QC checklist for realism, readability, and brand fit.
- Retry prompts for cluttered UI, weak lighting, generic stock-photo results, or unrealistic screens.

## Hero Image Direction

Scene:

- A cinematic studio desk at night or late afternoon.
- One operator's workspace, not a corporate office.
- Five elegant production cards or screens arranged as lanes.
- Mission 001 card visible as the focal point.
- QA checklist and archive manifest visible but not cluttered.

Mood:

- Premium.
- Disciplined.
- Quietly powerful.
- Precise.
- Founder-operated.

Materials:

- Matte black desk.
- Brushed metal details.
- Glass screen reflections.
- White paper mission cards.
- Deep red accent markers.

Lighting:

- Soft cinematic key light.
- Controlled contrast.
- Subtle neon line accents.
- No overpowering glow.

## Carousel Visual Variations

1. Idea chaos vs mission clarity.
2. Five production loop station layout.
3. Codex task running inside one loop.
4. QA checklist and archive wall.
5. Mission handoff card to the next loop.

## Negative Prompt Concepts

Avoid:

- Robot mascots.
- Fantasy sci-fi control rooms.
- Crowded corporate dashboards.
- Unreadable text-heavy screens.
- Random fake logos.
- Messy cables and visual clutter.
- Plastic-looking people.
- Stock-photo smiles.
- Overexposed neon.

## QC Criteria For Future Prompt Loop

- [ ] Image reads as a premium solo studio, not a corporate office.
- [ ] Five production loops are implied without unreadable clutter.
- [ ] Mission 001 is visually central.
- [ ] Composition leaves Instagram-safe negative space.
- [ ] Lighting feels cinematic and realistic.
- [ ] No fake third-party logos.
- [ ] No malformed hands, screens, or text-heavy UI.
- [ ] Visual can support campaign captions.
