# Mission 001 Instagram Upload Plan

## Campaign

Loop Mission - Build The Studio Loop

## Goal

Prepare the structure for Instagram-ready assets without generating images yet.

## Recommended Content Set

### Post 1: Brand Introduction Carousel

- Format: 7-slide carousel.
- Objective: explain Loop Mission as a one-person AI studio production system.
- Primary CTA: "Start with one mission."
- Asset needs: one hero image, five-loop diagram-style image, QA/archive close-up.

### Post 2: Premium Studio Desk Hero

- Format: single image post.
- Objective: establish premium brand mood.
- Primary CTA: "Build the studio loop."
- Asset needs: cinematic studio desk image.

### Post 3: Mission Workflow Reel

- Format: 20-30 second Reel.
- Objective: show the transformation from idea to validated output.
- Primary CTA: "Choose one loop."
- Asset needs: vertical storyboard frames, motion captions, end card.

### Post 4: Five Production Lines Carousel

- Format: 5-6 slide carousel.
- Objective: introduce the five loops individually.
- Primary CTA: "Pick your first production line."
- Asset needs: one visual card per loop.

### Post 5: QA And Archive Trust Post

- Format: single image or 3-slide mini-carousel.
- Objective: show why the system is reliable.
- Primary CTA: "Do not just create. Validate and archive."
- Asset needs: checklist close-up, archive manifest visual.

## Image Requirements For Later Generation

- Aspect ratios: 4:5 feed, 1:1 square backup, 9:16 Reel frames.
- Safe area: leave space for top headline and bottom CTA.
- Style: cinematic, premium, editorial, high contrast.
- Avoid: unreadable UI, fake brand logos, generic AI robot imagery, cluttered screens.

## Caption Draft Directions

Caption set should include:

- Short caption under 80 words.
- Story caption around 150-220 words.
- Direct CTA version.
- Founder-note version.
- Hashtag groups by audience, workflow, AI studio, and creative production.

## Upload Checklist

- [ ] Final image or video exists.
- [ ] Caption selected.
- [ ] Hashtags selected.
- [ ] Alt text drafted.
- [ ] CTA matches the post objective.
- [ ] Visual has readable negative space.
- [ ] No unlicensed logos or vendor assets.
- [ ] No claims that overpromise automation.
