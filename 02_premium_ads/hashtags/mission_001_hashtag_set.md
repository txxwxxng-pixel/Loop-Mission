# Mission 001 Hashtag Set

## Campaign

Loop Mission - Build The Studio Loop

## Usage Rules

- Use 8-15 hashtags per post.
- Mix broad, niche, and Korean tags.
- Do not stuff unrelated trending tags.
- Keep the hashtag set aligned with production, AI workflow, design, and solo studio operation.
- Rotate sets by post type to avoid repetitive spam signals.
