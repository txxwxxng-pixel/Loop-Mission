# Design Planning Automation for Loop Mission

This document defines a planning layer for Loop Mission.

## Purpose

The planning layer connects creative planning, visual concept prompts, image review, Codex handoff, implementation tasks, review, and learning updates.

## Main Flow

1. Codex creates a planning brief.
2. Codex creates visual concept prompt options.
3. The selected visual concept is reviewed.
4. Codex converts the selected concept into a build spec.
5. Codex creates an implementation task.
6. Codex builds in a worktree.
7. The result is reviewed.
8. Learning files are updated.

## Target Loops

- 01_interactive_web
- 04_photoreal_prompts
- 05_unity_2d_games

## Planning Outputs

- Creative brief
- Visual direction options
- Image prompt pack
- Design review scorecard
- Image to build spec
- Codex implementation task
- Planning run report

## Rule

Planning can be automated with templates, scoring criteria, reusable skills, prompts, run reports, and learning files. Final visual taste decisions should remain human reviewed when the direction matters.
