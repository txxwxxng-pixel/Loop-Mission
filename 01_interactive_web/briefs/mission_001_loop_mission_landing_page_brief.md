## Objective

Create a practical interactive landing page MVP for Loop Mission that presents it as a premium one-person AI studio operating system with five production loops.

## Core Offer

Loop Mission turns ideas into production missions. Each mission produces a real output, passes QA, enters the archive, and prepares the next handoff.

## Audience

- Solo founders.
- Independent creators.
- Designers, developers, and makers using Codex workflows.
- Small studio operators who need repeatable production across web, ads, image prompts, Unreal spaces, and Unity/game commerce.

## Page Sections

1. Hero section with first-viewport Loop Mission signal.
2. Five production loop sections.
3. Mission workflow section.
4. Premium AI studio positioning section.
5. Output archive section.
6. CTA section.

## Interactive Requirements

- Loop selector for five production lines.
- Workflow steps that reveal practical output details.
- Hover and focus states for loop panels, CTA, and image placeholders.
- Subtle motion that supports the premium studio mood without becoming sci-fi.

## Visual Direction

- Dark graphite and matte black foundation.
- White text and white card surfaces for mission artifacts.
- Deep red accent.
- Cinematic editorial feel.
- Original visual language.
- Placeholder areas for future generated images from the photoreal prompt pack.

## Out Of Scope

- No generated images.
- No Streamlit.
- No web framework dependency.
- No Unreal or Unity files.
- No production branch merge to main.

- Static MVP exists under `01_interactive_web/projects/mission_001_loop_mission_landing_page/`.

- Project has a README with exact run options.
- Handoff manifest and QA report exist.
- No files outside `01_interactive_web/` are modified.
