# Mission 001 Loop Mission Landing Page MVP

## Project Type

Self-contained static HTML/CSS/JS landing page. No package install is required.

## Run

Open directly:

```text
01_interactive_web/projects/mission_001_loop_mission_landing_page/index.html
```

Optional local server from this folder:

```powershell
python -m http.server 4173
```

Then open:

```text
http://localhost:4173
```

## Files

- `index.html` - page markup and content.
- `styles.css` - responsive visual system and motion.
- `script.js` - loop selector, workflow selector, and small scroll interactions.

## Notes

- Image slots are intentional placeholders for future generated visuals.
- No external assets, dependencies, Streamlit, Unreal files, or Unity files are used.
