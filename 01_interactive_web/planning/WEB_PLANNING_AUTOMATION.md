# Interactive Web Planning Automation

## Goal

Automate planning for interactive web deliverables before Codex implementation.

## Target Output

Each web planning run should produce:

- creative brief
- reference interpretation
- image prompt pack
- selected visual direction
- section map
- component map
- motion spec
- build task
- QA checklist
- learning update

## Recommended Web Planning Flow

1. Read references.
2. Define web product goal.
3. Generate two or three design directions.
4. Create image prompt options for visual exploration.
5. Select or review the concept image.
6. Convert selected concept into build spec.
7. Create Codex implementation prompt.
8. Build in worktree.
9. Review and update WEB_LEARNINGS.md.

## Web Planning Dimensions

- brand mood
- hero section
- section flow
- navigation
- typography hierarchy
- background system
- interactive elements
- motion language
- responsive behavior
- conversion goal

## Default Target Style

Premium white tone, Dolby Atmos music studio, clean futuristic interior, high-end audio visual identity, interactive editorial website, soft motion, and minimal UI.

## Build Spec Must Include

- pages
- sections
- components
- states
- animations
- assets
- CSS or token direction
- responsive rules
- validation command
