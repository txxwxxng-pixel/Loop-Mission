[Describe the product or experience goal.]

Visual direction:
[White tone, Dolby Atmos music studio, futuristic, editorial, or other style direction.]

Screen:
[Desktop landing page, mobile screen, hero section, or full homepage concept.]

Composition:
[Describe layout hierarchy, hero, panels, navigation, and content zones.]

Interaction implication:
The design should visually suggest [scroll interaction, hover panels, audio-reactive UI, or spatial navigation], while remaining a static concept image.

Style:
premium, minimal, high-end, clean UI, realistic material response, elegant typography hierarchy, strong spacing, modern web design, suitable for implementation.

Constraints:
No fake readable body text, no watermark, no logo, no messy UI, no excessive decoration.

Output:
A clear web design concept frame that Codex can convert into layout, components, CSS, and motion spec.
