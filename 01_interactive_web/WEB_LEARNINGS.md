## Build Rules

- Keep each iteration small enough to validate.
- Prefer a clear hero, section flow, and responsive layout before adding complex effects.
- Record build commands and preview steps in each run report.
- Treat selected visual concepts as direction, not pixel-perfect requirements.

## Review Dimensions

- layout clarity
- visual identity
- interaction clarity
- responsive behavior
- build reliability
- implementation feasibility
- conversion or portfolio value
