# ROADMAP.md

## Phase 1: Base Studio Operating System

- Create repo structure.
- Add `AGENTS.md`, studio rules, loop master documents, shared templates, roadmap, sprint board, and repo map.
- Keep the system documentation-first and execution-focused.

## Phase 2: Five Production Branches/Worktrees

- Create one branch or worktree per production loop.
- Keep loop-specific experiments out of `main`.
- Define first mission folders for each loop.

## Phase 3: First Output Loop Tests

- Run one small independent mission per loop.
- Validate each output against its loop definition of done.
- Record QA reports and output manifests.
- Do not treat the five loops as one mandatory sequence.

## Phase 4: Repeatable Production Archive

- Standardize archive folder names.
- Ensure each completed mission includes a brief, final output, QA report, and manifest.
- Review which mission types are repeatable.

## Phase 5: Monetization-Ready Product/Output Pipelines

- Convert repeated outputs into productized workflows.
- Add marketplace, deployment, upload, or sales-readiness checklists.
- Keep automation practical and loop-specific.
