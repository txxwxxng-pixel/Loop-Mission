# Unity 2D Design Image Prompt Template

Use this for ChatGPT image-based Unity 2D design exploration.

```text
Create a premium 2D mobile game design concept for [GAME CONCEPT].

Goal:
[Describe the gameplay and emotional goal.]

Screen:
[Title screen, gameplay screen, HUD mockup, character concept, or stage concept.]

Visual direction:
[casual premium, cozy, clean, arcade, puzzle, collectible, or other style direction.]

Composition:
Show a clear 2D game screen layout with readable player object, interactable objects, UI or HUD area, and strong visual hierarchy.

Gameplay implication:
The image should clearly suggest the core loop: player action, feedback, reward, and progression.

Style:
high-quality 2D mobile game art, clean readable silhouettes, app-store-ready visual clarity, polished UI, strong color identity, production concept art.

Constraints:
No unreadable fake text, no watermark, no logo, no overly complex background, no confusing UI, no 3D photoreal look unless requested.

Output:
A clear Unity 2D game design concept that Codex can convert into scene, prefab, script, asset, and UI specs.
```
