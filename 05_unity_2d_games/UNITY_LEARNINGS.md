## Build Rules

- Keep the MVP small enough to test.
- Define core loop, controls, scene list, and asset list before implementation.
- Avoid committing Unity generated folders by default.
- Treat visual concepts as direction, not final production assets.

## Review Dimensions

- core loop clarity
- input responsiveness
- scene structure
- script structure
- asset feasibility
- mobile readability
- monetization potential
