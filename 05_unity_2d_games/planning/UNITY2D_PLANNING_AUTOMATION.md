# Unity 2D Planning Automation

## Goal

Automate planning for Unity 2D game design before implementation.

## Target Output

Each Unity planning run should produce:

- game creative brief
- reference interpretation
- core loop
- visual direction
- image prompt pack
- selected concept handoff
- asset list
- scene list
- script list
- MVP build task
- QA checklist
- learning update

## Unity Planning Flow

1. Read references.
2. Define player fantasy and core loop.
3. Define monetization angle.
4. Generate two or three visual directions.
5. Create image prompt options.
6. Select or review the visual concept.
7. Convert selected image into Unity build spec.
8. Create Codex implementation task.
9. Build or prepare Unity-ready structure.
10. Review and update UNITY_LEARNINGS.md.

## Planning Dimensions

- genre
- core loop
- player goal
- session length
- controls
- camera
- UI or HUD
- stage structure
- character and objects
- reward loop
- monetization
- asset production risk

## Default Output Style

Prefer small MVPs that can be built and tested quickly.

Avoid overlarge RPG or platformer scopes unless the task explicitly asks.
