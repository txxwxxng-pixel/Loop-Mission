# Loop Planning Director

## Use When

Use this skill when a task needs planning before design or implementation.

## Main Outputs

- creative brief
- visual direction options
- image prompt pack
- image review scorecard
- image-to-build spec
- Codex implementation task
- planning run report

## Rules

- Do not implement code unless explicitly asked.
- Keep each plan buildable in one iteration.
- Separate web, image prompt, and Unity tasks.
- Prefer specific, testable outputs.
- Use plain markdown.
- Do not use HTML.

## Completion

End with:

- planning files created
- selected or proposed direction
- what needs visual generation
- what Codex can implement next
