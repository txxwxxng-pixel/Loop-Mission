# Web Design Brief Builder

## Scope

Work with:

- 01_interactive_web/

- web creative brief

- Codex implementation task draft

## Design Priorities

- premium visual identity
- clear layout hierarchy
- buildable components
- responsive structure
- motion direction
- conversion goal

- unbuildable abstract visuals
- overloaded UI
- HTML output in planning docs
