# Unity 2D Game Design Brief Builder

## Scope

Work with:

- 05_unity_2d_games/

## Required Output

- game creative brief
- core loop
- controls
- monetization angle
- visual direction options
- image prompt pack
- image-to-build spec
- Codex implementation task draft

## Design Priorities

- simple playable MVP
- clear core loop
- mobile readability
- asset feasibility
- retention hook
- monetization path

## Avoid

- overlarge game concepts
- unclear controls
- asset-heavy plans for first iteration
