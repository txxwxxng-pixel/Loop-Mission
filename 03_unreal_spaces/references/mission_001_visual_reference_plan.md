# Mission 001 Visual Reference Plan

## Reference Goal

Translate the reviewed Mission 001 campaign and photoreal prompt language into an Unreal-ready reference plan for a premium AI studio operations room.

- Mission 001 Premium Ads campaign brief.
- Mission 001 campaign concept.

These are conceptual references only. Do not copy third-party brand visuals, real UI, logos, or real-person likenesses.

## Visual Pillars

### Premium Solo Studio

- One operator scale.
- Focused room rather than giant command center.
- Central table as the working anchor.

### Five Production Lanes

- Physical zones are clear from a hero camera angle.
- Each zone gets a distinct panel/card cluster.
- Zone identity should be readable by layout and color accents, not logos.

### QA And Archive Proof

- Archive wall provides trust and continuity.
- QA checklists and manifests appear as physical panels.
- Deep red validation marks show completion status.

### Cinematic Editorial Realism

- Realistic materials.
- Controlled contrast.
- Practical lights.
- Minimal abstract screen shapes.

## Palette

- Matte graphite base.
- Deep black floor and table surfaces.
- Warm white illuminated panels.
- Brushed metal trim.
- Deep red accent marks.
- Soft desaturated reflections.

## Avoid

- Generic sci-fi bridge.
- Hologram-heavy command center.
- Cluttered hacker room.
- Neon overload.
- Robot mascots.
- Trademarked logos.
- Readable fake third-party UI.
- Overly large corporate control room.
