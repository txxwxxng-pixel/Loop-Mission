# QA Rules

## Required QA For Every Mission

- Confirm the target production loop.
- Confirm all output files are in the correct folder.
- Confirm deliverables match the loop master document.
- Confirm no unrelated folders were modified.
- Confirm no secrets or generated engine folders were added.
- Record partial validation clearly when full validation is not possible.

## Loop-Specific QA

- Interactive web: check responsive layout, run guide, asset references, and browser notes when a prototype exists.
- Premium ads: check brand consistency, prompt clarity, caption readiness, aspect ratio plan, and platform fit.
- Unreal spaces: check scale assumptions, asset manifest, blockout plan, script plan, and render path.
- Photoreal prompts: check full prompt, compact prompt, negative prompt, variations, QC failures, and retry prompt.
- Unity 2D games: check core loop, MVP scope, monetization plan, store asset plan, and implementation risks.

## QA Report Minimum

- Mission name.
- Target loop.
- Files reviewed.
- Checks performed.
- Pass/fail notes.
- Blockers.
- Recommended next action.
