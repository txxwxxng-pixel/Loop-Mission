# Codex Workflow Rules

## Before Editing

- Read `AGENTS.md`.
- Read the requested task or goal document.
- Inspect the target folder.
- Identify fatal blockers before writing files.

## During Editing

- Keep edits scoped.
- Prefer markdown operating documents and templates for foundation tasks.
- Use existing folder names exactly.
- Do not add app scaffolding unless requested.
- Do not add code when documents or templates satisfy the mission.

## After Editing

- List created or modified files.
- Validate folder and file references.
- Check that no cross-loop conflicts were introduced.
- Report blockers and risks.
- Recommend one concrete next Codex task.

## Reporting Format

Use:

1. Summary.
2. Files created/modified.
3. Key operating rules added.
4. Validation performed.
5. Remaining blockers or risks.
6. Recommended next Codex task.
