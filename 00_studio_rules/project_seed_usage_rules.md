# Project Seed Usage Rules

## Definition

A project seed is a top-level planning document. It can describe a brand, world, product category, target market, monetization goal, visual tone, reference direction, and execution priorities.

## What A Project Seed Is For

- Give one or more loops a shared starting context.
- Keep high-level project direction in one reusable place.
- Help Codex understand brand, market, tone, constraints, and priorities before planning a loop mission.
- Provide source context for `/plan` or `/goal`.

## What A Project Seed Is Not

- It is not production content by itself.
- It is not a mandatory five-loop workflow.
- It does not mean all five loops must run in sequence.
- It does not authorize Codex to edit every loop.

## Usage Rule

Each independent loop may read the project seed and produce its own output. Codex should only execute the target loop unless the user explicitly asks for cross-loop coordination.

## Example Path

```text
90_shared_assets/project_seeds/seed_001_premium_ai_studio_brand_pack.md
```

## Cross-Loop References

Cross-loop references should be written as handoff manifests. If a seed is used by multiple loops, each loop still needs its own mission ID and output contract.
