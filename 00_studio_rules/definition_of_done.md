# Definition Of Done

## Repository Task Done

- Required files or folders exist.
- Folder references are accurate.
- Cross-loop boundaries are clear.
- No forbidden files are created.
- Validation results are reported.

## Production Mission Done

- Mission brief exists.
- Output requirements are satisfied.
- QA report exists.
- Production output manifest exists or is planned.
- Archive destination is named.
- Remaining blockers are explicit.

## Real Output Requirements

A real output must be:

- Usable by the user without hidden context.
- Stored in the correct loop folder or archive.
- Named clearly enough to find later.
- Validated against a checklist.
- Ready for review, continuation, export, or publication.

## Not Done

- Vague strategy without deliverables.
- Mixed-loop work without permission.
- Missing QA notes.
- Unclear folder destination.
- Unversioned overwrite of user output.
- Hidden dependency on local secrets or generated engine files.
